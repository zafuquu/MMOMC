# MMOMC Roadmap

## Milestone 0 — Buildable core
- [x] NeoForge 1.21.1 / Java 21 project structure
- [x] Persistent level, EXP, and four manual stats
- [x] EXP rewards from hostile living entities
- [x] First job selection at level 10
- [x] Second-job specialization at level 50
- [ ] CI build verified green
- [ ] In-game smoke test on client and dedicated server

## Milestone 1 — RPG rules and combat
- [ ] Apply STR/STA/DEX/INT to real gameplay attributes and derived stats
- [ ] Health/mana model and configurable formulas
- [ ] Job skill data model, skill points, cooldowns, and server-side validation
- [ ] Assist healing, buffs, and resurrection
- [ ] Death/respawn and progression edge-case tests

## Milestone 2 — Equipment and refinement
- [ ] RPG equipment slots and rarity tiers
- [ ] Accessory stats and buffs
- [ ] Refinement +1 to +20
- [ ] Aura/ability milestones at +5, +10, +15, +20
- [ ] Enhancement materials, failure rules, protection stones, and pity protection
- [ ] Item serialization and multiplayer exploit tests

## Milestone 3 — Combat content and loot
- [ ] Hostile RPG mobs, elites, and bosses
- [ ] Boss-specific loot tables and personal/shared/hybrid loot settings
- [ ] Party eligibility, contribution, and anti-exploit rules
- [ ] Dungeons, boss mechanics, and encounter rewards

## Milestone 4 — Multiplayer social systems
- [ ] Party invitations, leader, member list, chat, and role display
- [ ] EXP distribution and party bonuses
- [ ] Need/Greed and personal loot settings
- [ ] Support targeting and party resurrection

## Milestone 5 — World and travel
- [ ] Data-driven generated starter city and NPCs
- [ ] Merchants, blacksmith, job master, skill master, bank, quest master
- [ ] Warp shrines and per-player discovery
- [ ] Warpstones and return-to-city
- [ ] Teleport restrictions for combat and dungeons
- [ ] Minimap/world-map markers and optional Xaero compatibility

## Milestone 6 — Endgame and polish
- [ ] Quests, titles, guilds, player trading, pets, and set bonuses
- [ ] Custom models, textures, sounds, particles, and animations
- [ ] Configurable server rules and balancing
- [ ] Dedicated-server regression suite and release packaging
